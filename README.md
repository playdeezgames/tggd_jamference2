# Roomba Rights of SPLORR!!

A cat tries to nap while a robot vacuum follows a route you can't see. Entry for [Jamference: AI Game Jam Hack 1](https://itch.io/jam/jamference-ai-game-jam-hack-1). Movement input only: arrow keys or WASD.

- Play: https://playdeezgames.github.io/tggd_jamference2/ (once GitHub Pages is enabled)
- itch.io: https://thegrumpygamedev.itch.io/roomba-rights-of-splorr
- Build: `ODIN=/path/to/odin ./build.sh`, serve `build/web` over HTTP. Update the Pages site with `tools/pages.sh`, then commit `docs/`.

## AI use

Claude (Claude Code) wrote all the code, the web shim and the build setup. The product owner made the design decisions with Claude and playtested as QA. See `ITCH_DESCRIPTION.md` for the full disclosure.
